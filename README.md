# 📦 API de Estoque SENAI

API REST desenvolvida para realizar o gerenciamento de produtos de um estoque.

O projeto foi desenvolvido utilizando **Node.js, Express, Prisma e PostgreSQL**, permitindo realizar operações de cadastro, consulta, atualização e exclusão de produtos.

---

## 🚀 Tecnologias utilizadas

- **Node.js** — ambiente de execução JavaScript
- **Express** — criação da API REST
- **Prisma ORM** — comunicação com o banco de dados
- **PostgreSQL** — banco de dados
- **Thunder Client** — testes dos endpoints

---

## 📋 Funcionalidades

A API permite:

- ✅ Cadastrar produtos
- ✅ Listar todos os produtos
- ✅ Buscar um produto pelo ID
- ✅ Atualizar produtos
- ✅ Excluir produtos
- ✅ Armazenar nome, quantidade, preço e categoria
